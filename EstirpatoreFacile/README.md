# 🌱 Estirpatore Facile

**Estirpatore Facile** è una macchina manuale e completamente green progettata per la rimozione di piccole radici e ceppi, parte della linea “Facile” insieme a [FruttOliva Facile](../README.md).

## ⚙️ Descrizione tecnica
- Tipo: Estirpatore meccanico manuale  
- Uso: Estirpazione di radici e ceppi  
- Peso medio: 3kg 
- Materiale principale: acciaio  
- Versione attuale: **v1.0**

## 📂 Struttura
La sezione contiene:
- `progetto/` → schede tecniche, disegni  
- `immagini/` → foto del prototipo  
- `documentazione/` → manuale,   
- `licenza_utilizzo_privati_e_aziende.pdf`
